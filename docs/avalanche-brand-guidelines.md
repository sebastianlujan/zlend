# Avalanche Brand Guidelines

## Logo

### Size & Placement
- Minimum width: **250px** (digital)
- Minimum margin: **100px** on all sides
- Always maintain clear space around the logo

### Color Usage
- **4-Color on dark background**: Full color logo on dark surfaces
- **4-Color on light background**: Full color logo on light surfaces
- **1-Color on red**: White logo on Ava Red background
- Never distort, rotate, or alter the logo proportions

### Symbol vs AVAX Token
- The **Avalanche symbol** (triangle) is used for brand identity
- The **AVAX token icon** is used specifically for the cryptocurrency/token representation
- Do not interchange these two marks

## Colors

| Name | Hex | Usage |
|------|-----|-------|
| **Ava Red** | `#FF394A` | Primary brand color |
| **Ava Blue** | `#3055B3` | Secondary brand color |
| **Secondary Blue** | `#058AFF` | Accent, links, interactive elements |
| **Light Gray** | `#F5F5F9` | Backgrounds, subtle surfaces |
| **Dark Gray** | `#161617` | Dark backgrounds, text |
| **Black** | `#000000` | Text, high contrast |
| **White** | `#FFFFFF` | Text on dark, backgrounds |

## Typography

### Headlines
- **Font**: Aeonik Medium
- **Size**: 85–120px
- **Line height**: 100%
- **Letter spacing**: -3%

### Subheads
- **Font**: Aeonik Regular
- **Size**: 32–38px

### Body Copy
- **Font**: Inter Regular
- **Size**: 16px
- **Line height**: 120%
- **Letter spacing**: -2%

### Developer / Monospace
- **Font**: Aeonik Fono
- Alternate font for developer-facing content and code

## Layout Guidelines

- Use generous whitespace and clear visual hierarchy
- Headlines should be bold and impactful
- Maintain consistent margins and padding across layouts
- Red is used strategically as an accent, not as a dominant fill
- Dark and light layout variants are both supported
